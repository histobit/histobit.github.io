# Histobit — тест стратегии SMA(20)

Публичный сайт для теста BTCUSDT и ETHUSDT на дневных свечах. Исходный проект хранится отдельно в приватном репозитории `zettts/btc-sma20-backtest`.

Каждый день в 01:20 UTC GitHub Actions получает закрытые дневные свечи из публичного API Binance Vision, обновляет `candles.json` и `eth-candles.json` и публикует эти файлы вместе с сайтом в GitHub Pages. Текущая незакрытая свеча в расчёт не попадает. Рабочий процесс можно запустить вручную в разделе Actions.

Страница также проверяет появление новых закрытых свечей непосредственно при открытии и каждый час, пока она открыта. При недоступности API используются файлы, опубликованные GitHub Pages.

Для локального просмотра запустите `python3 -m http.server 8000` в каталоге репозитория и откройте `http://localhost:8000`. Демо-вход: `123 / 123`; это проверка в браузере, а не защита доступа.
